# SpecMatch — подбор закупок под товар по характеристикам ТЗ

Сервис находит закупки (44-ФЗ / 223-ФЗ), читает **текст ТЗ** и выдаёт по каждой
вердикт: **проходит / не проходит / нужно подтвердить** — с процентом и разбором
по каждому требованию. Отличие от конкурентов: матчинг по **фактическим
характеристикам ТЗ**, а не по классификаторам ОКПД2/КТРУ.

Полная архитектура и план — в [`plan.md`](plan.md).

## Запуск

```bash
# сопоставить товар с требованиями закупки
python3 scripts/run_match.py \
    data/products/gloves_nitrile.json \
    data/requirements/gloves_tender_01.json \
    data/profiles/gloves.json

# тесты ядра
python3 tests/test_matcher.py
```

## Принцип

Массив закупок держит **код + эмбеддинги**. LLM (Claude) подключается точечно —
только к финалистам, для извлечения требований из грязного ТЗ и текста вердикта.
Числовая логика соответствия (≥, ≤, наборы, дисквалификаторы) — детерминированный
код, без LLM. См. `plan.md` §2.
