# Эталонный набор (golden set) — Этап 0

Здесь лежат пары «извлечённые требования → эталонный вердикт эксперта» по реальным
закупкам. Это regression-набор для валидации ядра (plan.md §8, Этап 0): на нём
прогоняем связку извлечение→матчинг повторно при любой правке промпта в
`src/extractor.py`, чтобы видеть, не просела ли точность.

## Как пополнять

```bash
# извлечь требования из реального ТЗ и сохранить сюда
.venv/bin/python scripts/run_pipeline.py \
    data/samples/<закупка>.docx \
    data/products/<товар>.json \
    data/profiles/<категория>.json \
    --save data/golden/<закупка>.json
```

Затем эксперт (фаундер) глазами сверяет вердикт с реальным ТЗ и, если требуется,
правит `<закупка>.json` руками — это и есть эталон.

Цель Этапа 0: **≥90%** совпадений вердикта с экспертной оценкой на 20-30 закупках.
